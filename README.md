### 🌍 Air Quality Forecasting

Hybrid time-series forecasting system combining:

**ARIMA + Conv1D-LSTM**

for forecasting six pollutants across 12 Beijing monitoring stations.

- Missing-value imputation
- Cyclical temporal features
- Decision Tree feature selection
- ARIMA residual modeling
- 24-hour sequential prediction
- **R² = 0.8637**
- **RMSE = 0.2726**
- **MAE = 0.1820**
